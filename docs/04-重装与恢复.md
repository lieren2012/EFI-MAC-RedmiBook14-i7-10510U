# 04 · 重装与恢复

## 先说结论

- **EFI 跟系统是分开的**：重装 macOS 不会动 `disk0s1` 上的 EFI，所以引导不会坏。
- **不需要关 SIP**：当前 `csr-active-config = 00000000`（SIP 全开）也能正常跑 SimpleHDA / VoodooI2C / AppleALC，因为全部通过 OpenCore 注入。重装后保持默认即可。
- **扩容必须重建 APFS 容器**，也就是必须重装（见 01 文档）。

---

## 方案选择

### 方案 A｜保留 Windows，macOS 扩到 ~723 GB（推荐）

删掉 `s5 (Untitled 615GB)` + `s6 (APFS 108GB)`，在两者位置重建一个 APFS 容器。

- Windows（s3/s4）不动、EFI 不动
- macOS 可用空间从 108 GB → 约 **723 GB**
- 代价：macOS 要重装，用户数据要迁

### 方案 B｜全盘只留 macOS（1 TB）

删掉 s2–s6，整盘一个 APFS 容器。Windows 彻底没了，换 1TB 全给 macOS。

### 方案 C｜不重装（零风险）

保持现状，把 615 GB 的 `Untitled`（ExFAT，macOS 可读写）当数据盘用，并设为 Time Machine 目标：

```bash
sudo tmutil setdestination /Volumes/Untitled
```

系统盘 46.9 GB 空闲，日常够用。**不想折腾就选这个。**

---

## 方案 A 的完整步骤

### 第 0 步：备份（最重要，别跳）

要备份的东西其实很少：

| 内容 | 大小 | 放哪 |
|---|---|---|
| `~/Downloads/ai-project/`（含本套文档 + EFI 备份） | 约 150 MB | **外部 U 盘**（≥16 GB） |
| 用户数据 `~/Documents`、`~/Desktop`、`~/Pictures`、`~/Downloads` | 约 5–6 GB | 外部 U 盘 |
| EFI（`efi-backup/EFI-2026-11-11.tar.gz`） | 51 MB | **同一只 U 盘 + 云盘各一份** |

> ⚠️ 不要备份到 `Untitled`（s5）—— 那个分区马上要被删掉。
> ⚠️ 不要只留在 macOS 系统盘上 —— 会被一起抹掉。

### 第 1 步：做 macOS 安装 U 盘

- 16 GB 以上 U 盘，`磁盘工具` 抹成 `Mac OS 扩展（日志式）/ GUID`
- 用 Tahoe 安装器：`sudo /Applications/Install\ macOS\ Tahoe.app/Contents/Resources/createinstallmedia --volume /Volumes/Untitled2`
- 或者直接用恢复模式联网安装（开机按住 `⌘R` 需要白苹果，黑苹果请走 U 盘）

### 第 2 步：进安装器，重建分区

1. U 盘启动 → `磁盘工具`
2. 选中 `Untitled`（615 GB）→ 点 `-` 删除
3. 选中 `Container disk1`（108 GB）→ 点 `-` 删除
4. 点左上 `+` 新建 → 格式 `APFS` → 大小用满（约 723 GB）
5. 退出磁盘工具 → 安装 macOS

> 注意不要碰 `系统`（85.9 GB NTFS）和 `软件`（214.8 GB NTFS），那是 Windows。

### 第 3 步：装完系统，恢复 EFI

新装的 macOS 不会改 EFI，理论上开机还是能引导。但为保险，进系统后执行：

```bash
cd ~/Downloads/ai-project/hackintosh-docs
bash restore-efi.sh
```

脚本会：挂载 ESP → 把现有 EFI 打包存到 `/tmp`（回滚用）→ 用备份覆盖 → 校验 `config.plist` 哈希 → 提示重启。

### 第 4 步：重启前检查（3 项）

1. `Misc → Security → SecureBootModel = Disabled`（不关 SimpleHDA 会起不来）
2. `Kernel → Quirks → DisableLinkeditJettison = True`（SimpleHDA 1.0.1 硬性要求）
3. `boot-args` 里保留 `-ibtcompatbeta`（Tahoe 蓝牙必需）和 `-vi2c-force-polling`（触摸板）

### 第 5 步：装完后验证（按顺序）

```bash
# 1. 蓝牙
system_profiler SPBluetoothDataType | grep -E "Address|State|Transport"

# 2. WiFi / 声卡设备
system_profiler SPAudioDataType | head -20

# 3. 触摸板（实例数 > 0 才算成功）
ioreg -r -c VoodooI2CHIDDevice | grep -c VoodooI2CHIDDevice

# 4. 声卡 layout（应看到 alc-layout-id = 15000000，即 21）
ioreg -l -w0 -r -c AppleHDADriver | grep -E "alc-layout-id|HDAConfigDefault" | head -2

# 5. 麦克风（会连录 3 次，期间请说话）
bash ~/Downloads/ai-project/audio-fix/miccheck.sh
```

## 恢复 EFI 的三种情况

### 情况 1：只是 EFI 坏了，系统还在

直接用本目录的 `restore-efi.sh`，或手工：

```bash
sudo mkdir -p /tmp/efi && sudo mount -t msdos /dev/disk0s1 /tmp/efi
# 先备份现有
sudo cp -R /tmp/efi/EFI /tmp/EFI-old-$(date +%H%M%S)
# 覆盖 OC 与 BOOT
sudo rm -rf /tmp/efi/EFI/OC /tmp/efi/EFI/BOOT
sudo cp -R ~/Downloads/ai-project/efi-backup/EFI-2026-11-11/OC  /tmp/efi/EFI/
sudo cp -R ~/Downloads/ai-project/efi-backup/EFI-2026-11-11/BOOT /tmp/efi/EFI/
sudo umount /tmp/efi
```

> `diskutil mount disk0s1` 在 Tahoe 上会失败，必须用 `mount -t msdos`。这是已知现象，不是 EFI 坏了。

### 情况 2：换了一块新硬盘

1. 新盘先分一个 ≥200 MB 的 EFI 分区（FAT32）
2. 装 macOS
3. 把 `EFI-2026-11-11/` 整个拷到新盘的 EFI 分区根目录（即 `EFI/OC/...`）
4. 开机按 `F12` 选 UEFI 启动项，或进 BIOS 把 `EFI/BOOT/BOOTx64.efi` 加进启动顺序

### 情况 3：升级 macOS 后坏了

Tahoe 大版本内（26.x）升级一般不影响。跨大版本时注意：
- `SimpleHDA` 要跟着更新（AppleHDA 又变了的话）
- `IntelBluetoothFirmware / BTPatcher` 要换对应版本
- 升级前先把整个 EFI 复制一份到 U 盘

## 避坑清单（血泪版）

1. **别启用 `SSDT-TPD0.aml`** —— 那是错的假设备（I2C0 / ELAN2303），会让触摸板永远不工作
2. **`layout-id` 只能是 21** —— 56 没麦克风，99 麦克风静音
3. **`AppleALC.kext` 必须 ~3.7 MB** —— 87 KB 的是资源剥离版，任何 layout 都无效
4. **`AppleHDA` 在 Tahoe 已被 Apple 删除** —— 没有 `SimpleHDA` 就没有模拟音频
5. **`SecureBootModel` 必须 `Disabled`** —— 否则 SimpleHDA 导致无法启动
6. **不要开着「系统设置 → 声音」面板** —— 它会锁住内置麦克风输入流
7. **SysReport 要 DEBUG 版 OC 才生效** —— 排查 ACPI 时是唯一手段
8. **EFI 挂载用 `mount -t msdos`** —— `diskutil mount` 在 Tahoe 下必失败
